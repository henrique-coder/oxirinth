# Modrinth API v3 Read-Only Metadata Reference

> Verified live against `https://api.modrinth.com` on **2026-11-20**.
> Scope: **Strictly read-only (`GET`) metadata retrieval** for Oxirinth `v0.1.0`. Write endpoints and binary downloaders are explicitly excluded.

---

## Base URL & Required/Recommended Headers

- **Production Base URL:** `https://api.modrinth.com`
- **Staging Base URL:** `https://staging-api.modrinth.com`
- **Request Headers:**
  - `User-Agent` _(strongly recommended)_: Descriptive client identifier following Modrinth's `github_username/project_name/version (contact)` format (defaults to `henrique-coder/oxirinth/0.1.0 (https://github.com/henrique-coder/oxirinth)` or a custom value via `build_user_agent()`).
  - `Authorization` _(optional)_: Personal Access Token (`api_key`) attached verbatim to lift authenticated quota / access scopes. Never persisted to disk cache keys or emitted in logs.
- **Response Headers Used by `oxirinth-engine`:**
  - `X-Ratelimit-Limit`: Window quota (default `300` requests/minute per IP).
  - `X-Ratelimit-Remaining`: Remaining requests in current window.
  - `X-Ratelimit-Reset`: Seconds until window reset.
  - `Last-Modified` / `ETag`: Conditional revalidation tokens (`If-Modified-Since` / `If-None-Match` -> `304 Not Modified`).

## Verified `/v3/search` Facet Keys

- `project_types:<token>` — e.g., `project_types:mod`, `project_types:minecraft_java_server`
- `loaders:<loader>` — for mods, plugins, shaders, datapacks (e.g., `loaders:paper`, `loaders:fabric`)
- `mrpack_loaders:<loader>` — for modpacks and Java servers (e.g., `mrpack_loaders:fabric`)
- `game_versions:<version>` — e.g., `game_versions:1.21.1` (note: legacy v2 `versions:<version>` returns `0` hits on `/v3/search`)
- `categories:<category>` — e.g., `categories:optimization`
- `environment:<env>` — e.g., `environment:client_only`, `environment:server_only`, `environment:client_and_server`

## 7-Domain Facet & Schema Matrix

Oxirinth exposes domain-specific client methods rather than generic `get_project` / `search_projects` wrappers. Rust injects the exact `project_types:<token>` facet on search and validates `expected in payload.project_types` on single/batch retrieval.

| Domain         | Injected Search Facet                 | Required `project_types` Token | Sync / Async Models                  | Search Hit Model  | Notes                                                                                         |
| :------------- | :------------------------------------ | :----------------------------- | :----------------------------------- | :---------------- | :-------------------------------------------------------------------------------------------- |
| Mods           | `project_types:mod`                   | `"mod"`                        | `Mod` / `AsyncMod`                   | `ModHit`          | Multi-type projects like `luckperms` (`["mod", "plugin"]`) are valid here.                    |
| Plugins        | `project_types:plugin`                | `"plugin"`                     | `Plugin` / `AsyncPlugin`             | `PluginHit`       | Multi-type projects like `luckperms` (`["mod", "plugin"]`) are valid here.                    |
| Resource Packs | `project_types:resourcepack`          | `"resourcepack"`               | `ResourcePack` / `AsyncResourcePack` | `ResourcePackHit` | Omits `loaders`, `environment`, and server-specific fields.                                   |
| Data Packs     | `project_types:datapack`              | `"datapack"`                   | `DataPack` / `AsyncDataPack`         | `DataPackHit`     | Multi-type projects like `terralith` (`["datapack", "mod"]`) are valid here.                  |
| Shaders        | `project_types:shader`                | `"shader"`                     | `Shader` / `AsyncShader`             | `ShaderHit`       | Keeps shader `loaders` (`iris`, `optifine`, etc.) and `gallery`.                              |
| Modpacks       | `project_types:modpack`               | `"modpack"`                    | `Modpack` / `AsyncModpack`           | `ModpackHit`      | Exposes `mrpack_loaders` cleanly as `mod_loaders`.                                            |
| Servers        | `project_types:minecraft_java_server` | `"minecraft_java_server"`      | `Server` / `AsyncServer`             | `ServerHit`       | Note: `project_type:server` returns `0` hits; must use `project_types:minecraft_java_server`. |
